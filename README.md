🎓 Student Management System

A simple and professional Student Management System built using Python. This project demonstrates Object-Oriented Programming (OOP), File Handling, Decorators, Logging, and CRUD operations.

🚀 Features

- Add Student
- View Students
- Search Student by Roll Number
- Update Student Information
- Delete Student Record
- Auto Roll Number Generation
- File-Based Data Storage
- Function Execution Logging
- Exception Handling

🛠 Technologies Used

- Python 3
- OOP (Classes & Objects)
- File Handling
- OS Module
- Decorators
- DateTime Module

📁 Project Structure

Student-Management-System/
│
├── main.py
├── manager.py
├── student.py
├── student.txt
├── log.txt
└── README.md

📌 How It Works

- Student information is stored in "student.txt".
- Roll numbers are generated automatically.
- All major functions are logged using a custom decorator.
- Users can perform complete CRUD operations:
  - Create (Add Student)
  - Read (View Student)
  - Update Student
  - Delete Student

▶ Run the Project

python main.py
